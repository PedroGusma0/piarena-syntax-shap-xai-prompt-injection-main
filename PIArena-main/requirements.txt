# torch: NÃO listado aqui de propósito, e vllm (abaixo) NÃO deixado sem pin.
# O wheel do vllm vem com PyTorch embutido/compilado contra uma versão exata
# ("The vLLM wheel bundles PyTorch and all required dependencies" — docs
# oficiais) e declara essa versão exata como dependência própria
# (torch==2.13.0/torchvision==0.28.0/torchaudio==2.11.0 pro vllm==0.29.0,
# conferido direto na metadata do PyPI). Se torch também fosse listado aqui
# com outro número, ou deixado sem pin nenhum ("latest"), pip teria que
# reconciliar dois requisitos conflitantes de torch na mesma resolução — foi
# exatamente isso que causou o pip backtrackear por 100+ releases de vllm
# num pod RunPod antigo, até tentar buildar vllm==0.1.3 do zero (que falha,
# CUDA inacessível dentro do sandbox de build isolado do pip). Deixar o vllm
# pinado e não listar torch evita esse conflito -- o pip resolve numa
# passada só, usando o que o vllm já exige.
#
# --extra-index-url abaixo é só pra pip buscar a variante CUDA certa desse
# torch exato -- troque cu129 pelo CUDA do seu pod/cluster antes de instalar
# (`nvidia-smi`, "CUDA Version: X.Y" no canto superior direito ->
# cu121/cu124/cu126/cu128/cu129/etc.).
--extra-index-url https://download.pytorch.org/whl/cu129
vllm==0.29.0
